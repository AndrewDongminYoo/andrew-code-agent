## OpenAI Codex

This project drives the `codex app-server` JSON-RPC interface and does not vendor, modify, or redistribute the Codex CLI itself.
You install Codex separately.

Two directories are machine-generated by Codex's own generators rather than written here, and are checked in so the protocol contract is reviewable and so the build does not require a Codex install:

- `src/generated/codex-app-server/` — TypeScript types
- `schemas/codex-app-server/` — JSON Schema documents

They are generated at the exact version pinned in `src/constants.ts` as `REQUIRED_CODEX_VERSION`, by:

```bash
codex app-server generate-ts --out src/generated/codex-app-server
codex app-server generate-json-schema --out schemas/codex-app-server
```

Upstream project: <https://github.com/openai/codex>, licensed under the Apache License, Version 2.0.
Because that output derives from an Apache-2.0 project, this repository is licensed under the same terms so the generated trees and the code around them carry one consistent license.

`test/contract/client.test.mjs` regenerates both trees into a temporary directory and compares them byte for byte, so the checked-in copies cannot drift from what the pinned Codex produces.
That gate is opt-in and needs a local Codex binary at the pinned version; see the README.
